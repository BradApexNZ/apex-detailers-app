# Apex HQ GUI Update - Phase 1

Phase 1 is a safe visual polish pass, not a full rebuild.

## Completed

- Updated the browser/app shell branding to Apex HQ.
- Changed the compact logo treatment from the old AD feel toward a cleaner APEX wordmark style.
- Added a more premium black/yellow command-centre feel.
- Improved hero card contrast, depth, glow, and visual hierarchy.
- Improved dashboard cards, action cards, stats, form fields, Hnry/payment cards, and bottom navigation styling.
- Tuned the six-tab mobile bottom nav for smaller iPhone screens.

## Intentionally not changed yet

- No public upload links.
- No paid Cloud Functions.
- No AI/photo quote automation.
- No major data model rewrite.
- No Hnry API automation.

## Next GUI phase ideas

- Replace the temporary CSS wordmark with the proper vector Apex logo when ready.
- Build a cleaner Today view with jobs, payments due, and follow-ups due.
- Add stronger status badge colours for Quote, Booked, In Progress, Completed, Invoice Sent, Paid, and Review Sent.
- Add improved empty states and onboarding prompts.
- Add vehicle profile cards and before/during/after photo gallery sections.
