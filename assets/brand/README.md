# Apex Detailers brand assets

| File | Use |
|---|---|
| `apex-logo-full-transparent.png` | Full logo (emblem + APEX DETAILERS wordmark), 990×703, transparent. Source for everything else (extracted from `../apex-logo-official.svg`). |
| `apex-emblem-transparent.png` | Wings + A emblem only, 965×421, transparent. Use on dark backgrounds, social avatars, stickers. |
| `apex-app-icon-1024.png` | App / home-screen icon master (iPhone, App Store-style). Emblem on dark charcoal with gold glow, inside the safe area. |
| `apex-app-icon-maskable-1024.png` | Same, extra padding for Android circle/squircle masks. |
| `apex-favicon-{16…128}.png`, `favicon.ico` | Browser tab icons, rendered per size and lightly sharpened so they stay crisp small. |
| `apex-app-icon-preview.png` | How the icon looks on iPhone, Android and in a tab. |

Live copies used by the sites are in `public/` (`apex-icon-*.png`, `apex-icon-maskable-512.png`, `favicon.ico`), mirrored to `apex-book/public/`.

Colours: ink `#0a0a0d`, gold `#e8b93a`.
